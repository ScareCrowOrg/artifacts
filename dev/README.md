# Artifacts — Dev

Development-time asset directory for the ScareVerseLab artifacts layer.

## Purpose

Holds development and debugging assets that are **not** part of the canonical
production runtime.  Contents here may include binary blobs, experiment
outputs, or placeholder files generated during local development workflows.

## Content Index

| File | Description |
|------|-------------|
| `null` | Binary placeholder file (152 KB) generated by a development toolchain step; not used in production |

## Notes

- Files in this directory are **not seeded** into production environments.
- Do not import or depend on assets from this directory in production code.
- Placeholder/null files can be safely ignored or removed after local development.
