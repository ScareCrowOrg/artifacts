# Conversation Tracing API - Implementation Summary

## Overview

This implementation adds API-level control for conversation tracing in the ScareVerse chat endpoint. Users can now enable/disable detailed conversation tracing per request.

## Changes

### 1. API Request Model (`backend/app/models/chat.py`)

Added `enable_tracing` field to `ProcessarIntencaoChatRequest`:

```python
enable_tracing: bool = Field(
    default=False, 
    description="Enable detailed conversation tracing for RAG pipeline observability..."
)
```

**Default:** `False` (tracing disabled unless explicitly requested)

### 2. Orchestrator State (`backend/app/orchestrator/langgraph/langgraph_state.py`)

State already includes tracing fields:
- `enable_tracing: bool` - Whether tracing is enabled
- `conversation_id: Optional[str]` - Unique conversation identifier
- `trace_cell_id: Optional[str]` - ID of the trace cell

### 3. Orchestrator Flow (`backend/app/orchestrator/langgraph/langgraph_chat_flow.py`)

Updated `ChatOrchestrator.process()` method:
- Added `enable_tracing` parameter
- Initializes all tracing-related state fields
- Propagates the flag through the LangGraph state machine

### 4. Chat Endpoint (`backend/app/routers/chat_router.py`)

Updated `/api/chat/processar` endpoint:
- Accepts `enable_tracing` in request body
- Passes flag to orchestrator
- Updated API documentation with tracing example

### 5. Configuration (`.env.example`)

Enhanced documentation for `ENABLE_CONVERSATION_TRACING`:
- Clarified it's a global default
- Documented that per-request flag can override it
- Explained tracing purpose and use cases

## Usage Examples

### Basic Request (Tracing Disabled - Default)

```json
{
  "intencao": "Criar uma célula para sistema de login",
  "assignee_id": "uuid_do_usuario",
  "modelo": "mistral"
}
```

```json
{
  "intencao": "Debug this RAG query",
  "assignee_id": "uuid_do_usuario",
  "modelo": "mistral",
  "selected_collections": ["scareverse_docs"],
  "enable_tracing": true

```

## Configuration

### Environment Variable

```bash
# Enable structured conversation tracing for RAG pipeline observability
# This is a global default that can be overridden per-request via the API
ENABLE_CONVERSATION_TRACING=false
```

**Note:** The environment variable sets the system-wide default. Individual requests can override this by setting `enable_tracing` in the request body.

## Propagation Flow

```
Client Request
  ↓
ProcessarIntencaoChatRequest.enable_tracing
  ↓
chat_router.processar_intencao_chat()
  ↓
orchestrator.process(enable_tracing=...)
  ↓
OrchestratorState.enable_tracing
  ↓
LangGraph Nodes (can access state["enable_tracing"])
```
