# GLB Content Viewer Cell

**Ephemeral viewer cell** for displaying 3D GLB/GLTF model content with Babylon.js.

## Overview

The `glb-content-viewer` provides a dedicated viewer for 3D models that have been generated by the 3D Mesh Prototyping Cell. It displays models via the shared `BabylonModelViewer.vue` component with viewport controls (auto-rotate, wireframe, grid) and download support.

## Usage

### Via CellFactory (from 3D Mesh Prototyping Cell)

After generating a 3D mesh, the 3D Mesh Prototyping Cell creates a `glb-content-viewer` instance:

```typescript
cellFactory.addChildCell('glb-content-viewer', {
  content_id: 'uuid-here',
  relative_url: '/runtime/user/.../mesh.glb'
})
```

### Properties

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `content_id` | `string\|null` | `null` | UUID of the persisted 3D content to display |
| `relative_url` | `string\|null` | `null` | Relative URL for direct file serving via Runtime File Server |

Either `content_id` or `relative_url` is required. When both are provided, `relative_url` takes precedence (avoids an extra API call).

## Actions (GlbContentCell.execute())

### `load`

Loads 3D content data and builds the model URL for Babylon.js display.

- If `relative_url` provided: builds full URL with `/artifacts` prefix (routes through RuntimeFileServer)
- If `content_id` provided: fetches content metadata via `GET /api/contents/{id}`

### `download`

Requests a file download via `postMessage FILE_DOWNLOAD` (cross-origin iframe compatible).

### `update-metadata`

Updates content metadata **in-place** via `PATCH /api/contents/{content_id}`.

- Fields: `tags`, `metadata`, `name`
- Requires ownership of the content (403 if not owner)

## View.vue States

| State | Condition | Display |
|-------|-----------|---------|
| **Loading** | Content being fetched | Spinner + "Carregando modelo 3D..." |
| **Error** | Failed to load content | Error message + "Try again" button |
| **Empty** | No `content_id` or `relative_url` provided | Placeholder illustration |
| **Loaded** | Content loaded successfully | BabylonModelViewer + action buttons |

## Viewport Controls

- **Auto-rotate**: Toggle automatic camera rotation
- **Wireframe**: Toggle wireframe rendering
- **Grid**: Toggle ground grid visibility
- **Download**: Download the GLB file via host shell

## Integration

- **3D Mesh Prototyping Cell**: Creates this cell as a child to display generated 3D models
- **CellFactory**: Standard `.addChildCell()` pattern
- **BabylonModelViewer**: Shared component from `artifacts/shared/components/viewers/`
- **Backend**: Requires `PATCH /api/contents/{content_id}` endpoint
