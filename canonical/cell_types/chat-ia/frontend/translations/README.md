# Chat IA Cell – Frontend Translations

## Purpose

Internationalization (i18n) translation files for the Chat IA Cell frontend.

## Content Index

| File | Description |
|------|-------------|
| [`en.json`](./en.json) | English translations |
| [`pt-BR.json`](./pt-BR.json) | Brazilian Portuguese translations |

## How to Add a New Language

1. Copy `en.json` to `{locale}.json` (e.g., `es.json`)
2. Translate all values (keep keys unchanged)
3. Register the locale in the cell's i18n configuration
