# Notebook Cells Admin Cell – Frontend Components

## Purpose

Vue 3 components for the **Notebook Cells Admin Cell** — admin interface for managing notebook cell instances, viewing JSON data, and filtering/inspecting cells.

## Content Index

| File | Description |
|------|-------------|
| [`JsonEditor.vue`](./JsonEditor.vue) | Interactive JSON editor — edit cell data inline with syntax validation |
| [`JsonViewer.vue`](./JsonViewer.vue) | Read-only JSON viewer with collapsible nodes and syntax highlighting |
| [`NotebookCellDetails.vue`](./NotebookCellDetails.vue) | Detail panel for a selected cell — shows full metadata, data, and audit log |
| [`NotebookCellFilters.vue`](./NotebookCellFilters.vue) | Filter controls — by cell type, notebook, status, date range |
| [`NotebookCellList.vue`](./NotebookCellList.vue) | Paginated list of notebook cells with type badges and quick-action buttons |
